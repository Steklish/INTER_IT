## 📉 1. Снижение размерности (`01_dimensionality_reduction.py`)

### Концепция архитектуры
Автоэнкодер имеет симметричную топологию «песочных часов» (Hourglass):
$$\mathbf{X} \in \mathbb{R}^{64} \xrightarrow{\text{Encoder}} \mathbf{z} \in \mathbb{R}^{2} \xrightarrow{\text{Decoder}} \mathbf{\hat{X}} \in \mathbb{R}^{64}$$

* **Бутылочное горлышко (Bottleneck $\mathbf{z}$)**: Слой минимальной размерности ($D=2$), заставляющий сеть отсеивать случайный шум и сохранять только сущностные нелинейные зависимости.
* **Почему автоэнкодер лучше PCA**:
  * PCA находит только **линейные** проекции (гиперплоскости).
  * Автоэнкодер за счет функций активации (GELU) способен "разворачивать" сложные свернутые нелинейные многообразия (спирали, сферы, торы).

### Результаты эксперимента:
* Ошибка восстановления **PCA (2 компоненты)**: $\text{MSE} = 3.5076$
* Ошибка восстановления **Автоэнкодера (2D)**: $\text{MSE} = \mathbf{1.1217}$
* 🏆 **Качество сжатия выше на 68.0%!**

## 🧹 2. Шумоподавляющий автоэнкодер (`02_denoising_autoencoder.py`)

### Задача
Очистка сложных импульсных сигналов (ЭКГ, сейсмограммы, акустика) от сильного электромагнитного и импульсного шума.

### Математический принцип
На вход подается искусственно зашумленный сигнал $\mathbf{\tilde{X}} = \mathbf{X} + \mathbf{\epsilon}$, но функция потерь оптимизируется относительно **чистого эталона**:
$$\mathcal{L}_{\text{DAE}} = \frac{1}{N} \sum_{i=1}^N \|\text{Decoder}(\text{Encoder}(\mathbf{\tilde{X}}_i)) - \mathbf{X}_i^{\text{clean}}\|^2$$

Сеть выучивает физическое многообразие правильной формы сигнала. Случайный шум лежит за пределами этого многообразия и при прохождении через Bottleneck естественным образом проецируется в ноль. В отличие от простых фильтров (Moving Average), DAE **не срезает крутые пики и высокочастотные зубцы**.

### Результаты фильтрации:
| Метод | Итоговый SNR (dB) | Ошибка MSE | Прирост чистоты сигнала |
| :--- | :---: | :---: | :---: |
| **Зашумленный вход** | 2.53 dB | 0.2520 | 0.0 dB (База) |
| **Moving Average Filter** | 9.18 dB | 0.0554 | +6.65 dB |
| **Conv1D Autoencoder (DAE)** | **14.52 dB** | **0.0173** | **+12.00 dB (MSE снижен на 93.1%)** |

## 🛡️ 3. Детекция аномалий и Root Cause Analysis (`03_anomaly_detection_ae.py`)

### Промышленный сценарий
Предиктивный мониторинг газовой турбины по 16 каналам (вибрации, температуры, давления, обороты).

### Принцип Semi-Supervised / One-Class обучения:
1. **Обучение ТОЛЬКО на норме**: На производстве почти нет размеченных аварий. Модель обучается исключительно на штатной безаварийной работе (0% аномалий).
2. **Инференс через ошибку реконструкции**:
   $$\text{Anomaly Score}(x) = \|\mathbf{x} - \mathbf{\hat{x}}\|^2$$
   * Норма $\to$ сеть легко восстанавливает знакомый режим $\to \text{MSE} < \tau$.
   * Авария (дисбаланс, перегрев, срыв потока) $\to$ нарушаются физические корреляции $\to \text{MSE} \gg \tau$.
3. **Локализация первопричины (Root Cause Analysis)**:
   Поскольку декодер восстанавливает каждый сенсор индивидуально, мы вычисляем вектор ошибок $|\mathbf{x}_j - \mathbf{\hat{x}}_j|$ и автоматически указываем инженеру конкретный датчик, ставший источником сбоя.

### Результаты на тестовых авариях:
* **ROC-AUC**: **1.0000** (идеальное разделение нормы и аварий)
* **Precision / Recall / F1**: **99.34% / 100.0% / 99.67%**
* **Root Cause**: Автоэнкодер безошибочно выделил датчик `Vib_Body` для дисбаланса, `Temp_Oil` для перегрева и `Press_Air` для срыва компрессора!

## 🎨 4. Вариационный автоэнкодер (VAE) и генерация (`04_variational_autoencoder.py`)

### Переход к генеративному ИИ
В стандартном автоэнкодере латентное пространство дискретно: между кластерами зияют пустоты. VAE делает латентное пространство непрерывным и гладким, предсказывая параметры распределения:
$$\mu(\mathbf{x}), \quad \log \sigma^2(\mathbf{x})$$

### Трюк перепараметризации (Reparameterization Trick)
Чтобы градиенты могли протекать через случайный процесс при Backpropagation, случайность выносится в независимый шум $\epsilon$:
$$\mathbf{z} = \mu + \sigma \odot \mathbf{\epsilon}, \quad \mathbf{\epsilon} \sim \mathcal{N}(0, \mathbf{I})$$

### Функция потерь ELBO (Evidence Lower Bound):
$$\mathcal{L}_{\text{VAE}} = \text{MSE}(\mathbf{\hat{x}}, \mathbf{x}) + \beta \cdot \mathcal{D}_{\text{KL}}\left(\mathcal{N}(\mu, \sigma^2) \parallel \mathcal{N}(0, \mathbf{I})\right)$$
Дивергенция Кульбака-Лейблера притягивает латентные точки к стандартному нормальному куполу, заполняя все пустоты.

### Возможности VAE:
1. **Генерация новых данных**: Подавая в декодер случайный шум $\mathbf{z} \sim \mathcal{N}(0, \mathbf{I})$, получаем абсолютно новые, физически правдоподобные образцы.
2. **Плавный морфинг (Latent Space Walk)**: Непрерывная интерполяция $\mathbf{z}(\alpha) = (1-\alpha)\mathbf{z}_A + \alpha \mathbf{z}_B$ демонстрирует бесшовную трансформацию одного физического процесса в другой без артефактов.
