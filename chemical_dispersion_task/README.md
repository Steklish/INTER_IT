# 🌊 Прогнозирование распространения химиката (TCE Plume Dispersion)

## 📌 Описание задачи и физическая постановка
В промышленной зоне произошла аварийная разгерметизация заглубленного резервуара с высокотоксичным органическим растворителем — **трихлорэтиленом (TCE)**. Загрязнитель проник в водоносный песчаный горизонт и переносится естественным потоком грунтовых вод по закону Дарси в сторону крупного городского водозабора **«Заречный»**.

Норматив СанПиН / предельно допустимая концентрация (ПДК) трихлорэтилена составляет **5.0 мкг/л**. Превышение этой отметки на водозаборе классифицируется как экологическая катастрофа.

Полная спецификация задачи приведена в файле [`TASK_SPECIFICATION.md`](./TASK_SPECIFICATION.md).

---

## 🎯 4 целевых выхода модели

Каждое решение должно рассчитать:
1. **`c_pred`**: Точечный прогноз концентрации TCE ($\text{мкг/л}$) для каждой тестовой точки $(x, y, z, t)$ из `queries_test.csv` (минимизация RMSE).
2. **`[c_lower, c_upper]`**: Калиброванный 90%-й доверительный интервал (Conformalized Quantile Prediction).
3. **`mass_2026`**: Общая масса растворенного TCE во всем водоносном пласте на дату `01.01.2026` (кг).
4. **`arrival_time`**: Дата или количество дней от старта (2021-01-01), когда концентрация на Заречном водозаборе впервые превысит порог **5.0 мкг/л**.

## 🚀 Инструкция по запуску

Все команды выполняются из директории `chemical_dispersion_task/`:

```powershell
cd chemical_dispersion_task
```

### 1. Генерация и обучение решений:
```powershell
# Запуск основного боевого решения (LightGBM)
python solution.py

# Запуск альтернативных подходов:
python baseline.py
python solution_gpr.py
python solution_pinn.py
python solution_numsim.py
```

### 2. Оценка качества и бенчмарк:
```powershell
# Оценка конкретного сабмишена
python scorer.py submission.csv submission_meta.json

# Запуск сравнительного бенчмарка всех алгоритмов
python benchmark.py

# Построение графика сравнения
python plot_comparison.py
```

### 3. Визуализация и дашборд:
```powershell
# Построение полного набора графиков гидродинамики и метрик
python visualize.py
```
Графики сохраняются в папку `plots/`, а интерактивный дашборд доступен в файле `dashboard.html`.
